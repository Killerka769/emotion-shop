# 🎨✨ Emotion Shop — Магазин эмоций и стикеров 🛍️💬

**Emotion Shop** — современный интерактивный магазин стикеров, где вы можете выразить свои эмоции ярко и красочно! 🌈😍 Будь то радость, грусть или вдохновение — здесь найдётся стикер на любой случай.

---

## 🚀 О проекте

Это frontend-приложение на React + TypeScript, которое позволяет пользователям просматривать, фильтровать и покупать стикеры за виртуальные монеты.  
Состояние приложения управляется через Zustand, а стили оформлены с помощью SASS для гибкости и удобства. 💻⚡

---

## 🔥 Ключевые особенности

- 🏷️ Удобная навигация с категориями стикеров  
- ⭐ Добавление стикеров в избранное  
- 🛒 Корзина для покупок с виртуальными монетами
- 🎁 Система случайных подарков: **при каждой покупке есть 20% шанс получить +5 монет**
- 🎨 Адаптивный и стильный интерфейс  
- ⚡ Быстрая загрузка и отзывчивость
